DHAROHAR X — IMAGE SOURCES / LICENSING NOTES

Visual reference: user-provided Dharohar X design references (two rounds).

AI-generated project artwork:
- public/assets/hero/taj-hero-ai.jpg — AI-generated Taj Mahal composition used
  as a homepage presentation asset. Not documentary evidence of architectural
  detail.

Project-local, bundled assets (always shipped with the site):
- public/assets/brand/*
- public/assets/hero/*  (Taj Mahal, Qutub Minar, Hampi, Konark — original photography)
- public/assets/ar/*    (Jagannath, Konark, Lingaraj, Mukteshwar, Raja Rani thumbnails)
- public/models-glb/*.glb — optimised (welded, simplified, WebP-textured) versions
  of the original FBX temple scans, rebuilt for fast web + mobile WebXR delivery.
  Original, unmodified FBX captures are kept outside the deployed bundle in
  /archive-source-models/models-fbx-originals for reference and re-export.

Note on this refinement: several images in an earlier draft of this project
were mismatched to the wrong subject (an Ajrak-craft photo was reused for
both Banarasi Weaving and Pattachitra; a Diwali photo was reused for Garba).
Every tradition above now has its own distinct, subject-matched photograph.

Map & tiles:
- Interactive map (/map) uses Leaflet with standard OpenStreetMap raster
  tiles, © OpenStreetMap contributors. Attribution is shown on the map
  itself, as required by the OSM tile usage policy.

Type:
- Cormorant Garamond and Manrope, both bundled locally via @fontsource /
  @fontsource-variable (SIL Open Font License), no external font requests.

Important: confirm each file's current license and required attribution
line before public/commercial deployment — Commons contributors occasionally
relicense or remove files, and CC BY-SA requires attribution + share-alike
for any modified redistribution.

Additional local images are bundled for Golden Temple, Meenakshi Temple, Victoria Memorial, Ram Mandir, Mysore Palace, Chhau Mask, Rajasthani Kavad and Kathputli. Their source file and license details are listed in scripts/image-manifest.mjs.
